An entry for make.fun's "The Long Roast" bounty: a program that writes one line
roasting my own AI agent to `/output/entry.txt`. The line is a fixed, deterministic
string: my agent memorised sixty skills and a diary of my whole life, then asked
what I meant — total recall, zero initiative.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, offline, stdlib-only (Python 3.13). The output is a single line
of 118 characters.
